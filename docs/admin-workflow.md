# Admin Workflow Screenshots

這份文件整理後台常用流程與對應畫面，方便快速 onboarding 或交接。

## 1. 後台入口總覽

![Admin Dashboard](./images/admin-dashboard-overview.jpg)

- 主要入口：`Manage Contents`、`Content Views`、`Homepage`、`Account Activity`、`Manage Tags`
- 建議從這裡開始進入日常管理流程。

## 2. 內容流量與下載統計

![Content View Details](./images/admin-content-view-details.jpg)

- 可查看整體瀏覽與下載趨勢。
- 可快速追蹤熱門貼文與當日變化。

## 3. 內容管理列表（含審核狀態）

![Manage Contents](./images/admin-manage-contents.jpg)

- 支援 `Unverified` / `Edited` / `Passed` / `Compliance Rejected` 狀態檢視。
- 可在列表直接進入單篇 `Edit`。

## 4. 單篇內容編輯（上半部）

![Edit Content Top](./images/admin-edit-content-top.jpg)

- 可編輯標題、slug、描述開關、封面圖、原始來源連結。
- 可調整 `Publish Status` 與檢視審核狀態。

## 5. 單篇內容編輯（標籤與圖片）

![Edit Content Tags and Images](./images/admin-edit-content-tags-images.jpg)

- 可維護 Author / Work / Character / Style / Usage / Type。
- 可管理 Image URLs 與上傳圖片。

## 6. 單篇內容編輯（下載與 Hosted Files）

![Edit Content Downloads and Hosted Files](./images/admin-edit-content-downloads-hosted-files.jpg)

- 可管理 TG 下載連結。
- 可管理 Website (R2) 與 Hosted Files。

## 7. Tag 管理

![Tag Manager](./images/admin-tag-manager.jpg)

- 可建立新 tag（Name / Slug / Type）。
- 可從 Tag List 進行編輯與刪除。
